# 陪伴角色 3D 动作原型

这是一个已实现的本地 WebGL 动作演示，使用本任务自建的简化人形角色。不是 Olivia Lin 官方模型，也不含从 BSide 或“智她”提取的角色、动作、声音或贴图。AIRI 仅作为架构参考，不是第二个需要设计的角色。

## 打开与交付

先按 README 安装依赖。在本目录运行 `npm start`（PowerShell 用 `npm.cmd start`），或使用对应系统启动脚本，复制终端输出的 `MOTION_DEMO_URL` 到 Chrome / Edge。地址也会写入本机 `runtime.json`。服务仅绑定 `127.0.0.1` 的系统分配空闲端口，不占用其他工程端口。用终端 Ctrl-C 停止。

Three.js 固定为 0.180.0；仓库不包含依赖目录，首次运行 `npm ci --ignore-scripts` 需要联网。依赖安装好后，播放不需要联网、密钥、账号、麦克风或摄像头。交互版 `index.html` 不应直接以 `file://` 打开，因为 ES 模块需要本地 HTTP 服务；仅观看实录的 `观看动作预览.html` 可以直接打开。`node_modules` 不能删除后仍期望离线运行。

- `index.html` / `app.mjs`：实际 WebGL 播放器、轨道相机、动作切换、逐帧查看、导出与录制。
- `motion.mjs`：姿态参数、微动作、状态优先级与连续混合。
- `rig.mjs`：35 骨骼的原创人偶；躯干为双骨骼权重蒙皮，四肢/头/手指为骨骼附属网格。不是完整写实皮肤或成品二次元角色。
- `output/companion-motion.glb`：本地烘焙的 glTF 2.0 二进制角色，含 9 段 30 fps 动画、35 关节及真实 skin 数据。
- `output/motion-preview.webm`：浏览器实际渲染画面的 24 秒无声预览。录制期间保持页面可见。
- `output/validation.json`、`output/glb-validation.json`：动作层与 GLB 回读测试结果。
- `output/preview.png`：辅助定格截图；主交付是交互动作、GLB 和视频。

使用“播放完整互动”观看约 42.5 秒序列，也可随时选择动作。按“我想接着说”打断当前动作进入聆听。逐帧查看会暂停动作；继续播放恢复。鼠标拖动旋转、滚轮缩放，侧面按钮用于核对手脸距离；显示骨骼可以检查实际关节运动。

浏览器“保存动画 GLB / 录制 / 保存画面”产生的新文件位于 `generated/`；`output/` 保留经过验证的基准交付。

## 角色与动作意图

本轮提议的气质是安静、专注、克制的陪伴者；这不是对任何官方角色设定的断言。动作先建立对视，再给出小幅身体回应；避免持续摇摆、每句都挥手和大幅弹跳。脚部保持地面接触，当前不含走路、坐下、钢琴演奏或物体交互。

状态按事件驱动，不依赖固定循环演出。完整互动按钮只是验收用编排，不是最终 AI 对话流程。微动作层独立持续运行：呼吸使用两个非同周期信号混合；视线和头部使用不同低频；眨眼间隔序列为 3.7 / 5.1 / 4.3 / 6.4 / 3.2 秒，单次约 240 ms、闭合快于睁开。该序列确定可复现，但仍会周期重复；产品化时应加入受控随机与上下文约束。

## 已实现状态表

角度为人体局部旋转。时长为单次持续时间；状态结束回待机。呼吸、眨眼与视线持续叠加。数值与 `motion.mjs` 对应。

| ID / 动作 | 时长 | 进入混合 | 核心姿态与节奏 | 表情/身体配合 | 触发建议 / 自动优先级 |
| --- | ---: | ---: | --- | --- | --- |
| idle / 安静陪伴 | 持续；导出 9 s 循环 | 650 ms | 手自然垂落，胸部微动；视线非同步漂移 | 轻微笑、完整眨眼，根节点固定 | 无交互 / 0 |
| listen / 侧耳聆听 | 6 s | 480 ms | 0–0.65 s 头转约 9°、侧倾约 4°；2–2.9 s 一次轻点头 | 身体前倾约 1.6°，手保持安静 | 用户开始讲话 / 80 |
| think / 认真思考 | 5.4 s | 600 ms | 0–1 s 抬右手至下颌侧前方；1–3.5 s 保持；3.5–5.1 s 放下 | 视线略上移、头轻偏、眉微抬，手指半收 | 等待组织回答 / 30 |
| speak / 轻声表达 | 6.8 s | 450 ms | 0.25–2.7 s 右手开放手势；3.25–6.1 s 左手补充；中间留白 | 两段示意口型，中间停顿；头部小幅韵律 | 语音播放 / 50 |
| wave / 见面问候 | 3.4 s | 420 ms | 0.15–0.95 s 抬右手至脸侧；腕部轻摆；末段落手 | 展指、轻笑、朝前对视 | 首次进入会话 / 40 |
| happy / 会心一笑 | 3.5 s | 480 ms | 0–0.7 s 双手轻收至身前；2.3 s 后放松 | 笑容加宽、眼裂略收，身体小幅前倾 | 正向反馈 / 35 |
| confused / 有点疑惑 | 3.8 s | 500 ms | 0–0.7 s 轻歪头约 7.4°、左手掌心抬起；2.6 s 后回落 | 单侧眉抬高，视线小幅上移 | 需要澄清 / 35 |
| nod / 温柔确认 | 2.3 s | 320 ms | 0.1–0.8 s 点头约 8.6°；1.4 s 回正，微小收尾 | 保持微笑，手部不抢戏 | 接受/理解一条明确输入 / 55 |
| bye / 下次再见 | 4.1 s | 500 ms | 与问候相近但抬手保持更久、收手更慢 | 头轻低约 4°，保留温和表情 | 会话结束 / 40 |

状态建议的语音/会话事件尚未接入 AI；现已实现手动触发与演示触发。脸部是几何化示意，眨眼通过眼组缩放、视线通过瞳孔位移，情绪通过嘴宽/眉/眼裂变化，不等于成品模型的 BlendShape 质量。

## 混合、中断与层所有权

当前帧语义姿态保存为过渡起点，使用五次平滑曲线在 320–650 ms 内趋向下一动作的动态目标。中断发生时不回到默认站姿再开始。参数层是平滑插值，手臂使用两段 IK 求出关节四元数。已测试 81 种动作对之间的快速切换、参数有限性与中断第一帧连续性；尚未做严格速度/加速度连续的运动匹配。

自动请求只有在优先级不低于当前状态，或当前状态已结束时才接受。同状态自动请求不会重启。手动点击及“我想接着说”始终覆盖当前状态；演示序列同样使用显式覆盖。聆听保持最高自动优先级；未来接入 VAD 时应在讲话期间续期，而不是每 6 秒重新播放点头。

通道所有权：

| 层 | 控制内容 | 冲突规则 |
| --- | --- | --- |
| 基础与呼吸 | 胸部轻微旋转/缩放 | 根与腿固定，避免足滑 |
| 语义动作 | 胸/头、双腕目标、手掌方向与卷指 | 当前语义状态独占，通过过渡混合 |
| 视线 | 瞳孔偏移、小幅头部附加角度 | 限幅叠加；用户指针只给轻微偏移 |
| 眨眼 | 眼裂闭合 | 闭合优先于快乐导致的轻微眯眼 |
| 情绪 | 笑宽、眉高/不对称、眼裂 | 不写 `mouth` 开合通道 |
| 示意口型 | `mouth` 开合 | 只有 speak 写入；切走后随过渡关闭 |

自然度仍有明确上限：三种轻微视线变体而非大型动作库；手势按示例片段编排，未按真实句子语义调度。产品接入建议问候冷却 30 秒、情绪/确认冷却 3–8 秒，并按语句停顿触发；这些冷却值是建议，尚未在手动播放器强制实施。

## GLB 与重定向

原型单位米，Y 向上、Z 向前，根固定，四肢静止方向向下。手臂长度为上臂 0.285 m、前臂 0.255 m；IK 将距离限制在 0.06–0.532 m，并使用外侧肘极向量。它不应直接套在任意比例模型上。

GLB 包含全部关节四元数轨道及表情节点的位移/缩放；idle 的 9 秒导出版本使用闭合周期，首尾一致。其余导出片段在开始和结束加回中性姿态的包络，默认按单次播放。播放器里的状态中断是运行时逻辑，不会自动成为 GLB 内的交互状态机。GLB 不是 VRMA 文件。

替换正式模型时需要：

1. 用户有权编辑/使用的 VRM、GLB 或 FBX，以及角色比例、静止姿态、表情通道和展示许可。无需上传到第三方。
2. 对照 `hips/spine/chest/neck/head/leftUpperArm/leftLowerArm/leftHand/rightUpperArm/rightLowerArm/rightHand` 等语义关节映射；确认左右及局部轴，建立源/目标 rest-pose 校正四元数，不能仅按名称直接覆盖旋转。
3. 根据目标骨长重算手部空间目标与肘极向量；重新检查手脸/衣服穿插。没有手指骨时降级为手掌姿态，不强行伪造映射。
4. 将眼裂/嘴/眉几何通道换为模型支持的 expression/BlendShape；眨眼、happy 与 AEIOU 对同一目标的写入必须统一仲裁。真实 TTS 音素或振幅驱动替换当前示意口型，音频中断同步关闭口型。
5. 若接入 AIRI，可在其渲染层读取对话/VAD/TTS 事件后交给动作调度器，再由 VRM 适配层执行。当前未修改 AIRI、未声称完成其集成，也未实现通用模型拖入即用。

## 性能和验证范围

当前场景 35 骨骼、44,954 渲染三角形；浏览器现场短时计数约 60 fps，仅代表这台 Mac、当前窗口的观察，不是跨设备性能保证。像素比上限 1.75，阴影贴图 2048²，后台隐藏且非录制时不继续渲染。正式移动端应降低阴影和像素比，复用几何/材质并测量 p95 帧时间。

运行 `node tests.mjs` 验证参数、眨眼、优先级、打断、回待机等 8 项行为。运行 `node validate-glb.mjs` 真实回读导出的 GLB，检查皮肤/骨骼/动画数、挥手世界坐标位移、270 个动画采样点以及 idle 首尾误差。画面检查不等于完整服装碰撞或皮肤质量验收。
