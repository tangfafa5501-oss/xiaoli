# 拟人 AI 入口「小离」：设计文档 v0.2

## 1. 愿景与目标用户
- 目标用户：完全没用过 AI 的普通人（也包括大量没有IT背景的人）第一次看到 AI 的UI界面就望而却步。
- 愿景：用一个好看、有品位的拟人形象当 AI 的"入口"，旨在尽量消除普通人对AI的隔阂。降低普通人使用AI的门槛。
- 形式：开源的小体量本地智能体，上线和合规暂不考虑。
- **一句话定位：小离是一个本地运行、写实形象、能实时说话的 BSide，底下用 AIRI 那样的模块化架构。**

## 2. 设计原则
1. 零配置：自带本地模型，一键安装或解压，按麦克风或打字就能聊。
2. 像跟人说话：尽量语音，少打字，少按钮，不出现专业术语。
3. 一切 DIY 都用自然语言完成，由 AI 自己引导用户配置。
4. 小而可扩展：本体只负责日常对话，复杂任务调用外部付费高级智能体。
5. 每次改动先预览，随时可撤销。

## 3. 整体架构
用户（语音/文字）→ 耳朵（语音识别）→ 大脑（本地小模型 + 工具调用）→ 嘴巴（语音合成）+ 身体（形象动作）
大脑可通过"工具动作"调用：外部 AI 服务（Gemini 等）、形象/声音设置、技能扩展。

## 4. 四个基本模块
| 模块 | 建议方案 | 体积（估算） |
|---|---|---|
| 外壳 | Tauri | 10–20 MB |
| 大脑 | Qwen3-1.7B 量化版，llama.cpp 运行 | 约 1.1 GB |
| 耳朵 | SenseVoice-Small int8 + VAD（说话检测） | 约 230 MB |
| 嘴巴 | Kokoro 或 MeloTTS | 100–200 MB |
| 身体 | Live2D 或 VRM | 10–30 MB |

## 5. 体积预算（估算）
| 档位 | 大脑大小 | 总体积 |
|---|---|---|
| 轻量 | 0.6B | 约 800 MB |
| 标准（推荐） | 1.7B | 约 1.5–2 GB |
| 增强 | 4B | 约 3 GB |

第一次启动时自动检测电脑配置，选择合适的档位。

## 6. 第一次打开
1. 解压或一键安装，双击打开。
2. 选择一个形象（提供几种默认风格，之后可改，也可 DIY）。
3. 角色主动打招呼，提示"按住说话"或直接打字。
4. 开始聊天，无需任何设置。

## 7. 对话式配置
大脑只能调用固定的几种动作：添加 AI 服务、保存密钥、测试连接、切换声音、更换形象、添加技能、撤销。
- 每个外部服务附带一份简短指引，AI 按指引一步步带用户完成。
- 密钥保存在系统钥匙串里，不明文存储。
- 每次修改先预览，用户确认后生效，可以撤销。

示例：
> 用户：我想用 Gemini。
> 角色：好呀，我带你弄。先打开这个网页拿一个密钥，拿到后直接念给我或者粘贴过来就行。
> （保存密钥 → 测试连接 → 成功）
> 角色：连上了！以后复杂的问题我会去问 Gemini。

## 8. 形象与 DIY
- 首次使用提供多个形象选项，之后随时更换。
- 支持用户 DIY：用自然语言描述想要的样子，由图像模型生成后预览确认。

## 9. 安全与隐私
- 日常对话全部在本地运行，不联网也能用。
- 只有用户主动配置外部服务时才会联网。
- 密钥存系统钥匙串；所有设置改动可撤销。

## 10. 技术选型
外壳 Tauri；推理 llama.cpp；识别 SenseVoice；合成 Kokoro / MeloTTS；形象 Live2D / VRM；外部模型首选 Gemini。

## 11. 与 Project AIRI、BSide 的对比和借鉴
一句话：AIRI 是开源但没有"灵魂"的骨架；BSide 是有灵魂的成品角色，但闭源、昂贵、互动浅。小离要把两者合起来：BSide 的角色感 + AIRI 的模块化架构 + 本地运行。

### 11.1 两者的区别
| 维度 | Project AIRI | BSide（米哈游，林Olivia） |
|---|---|---|
| 定位 | 开源框架，面向会折腾的技术用户 | 闭源成品应用，面向普通用户 |
| 形象 | Live2D / VRM，实时驱动 | 3D 动捕，预渲染成视频片段 |
| 互动 | 实时文字和语音聊天 | 以"信件"为主，每天约 3 次 |
| 运行 | 本地或接 API，需要自己配置 | 全云端，需登录；成本高，上线不到两个月即关停 |
| 人设 | 空白，需用户自己设定 | 完整人设和故事，B 站提前预热约一年 |

### 11.2 从 AIRI 借鉴
- 大脑 / 耳朵 / 嘴巴 / 身体 的模块化架构，各模块可替换。
- 语音识别、语音合成和口型同步的实现思路。
- 大量外部服务商的接入方式，作为"对话式配置"的参考。
- 原有评估仍成立：MIT 开源、功能完整；但体积大（Windows 安装包约 733 MB，不含模型），首次使用要选服务商、填配置，对新手门槛高。

### 11.3 从 BSide 借鉴
- 写实形象用预渲染的循环视频片段，按场景和情绪切换，比 Live2D 更贴近写实风格。
- 先有角色，再有功能：用户记住的是"小离"，不是一个工具。
- 日常仪式感：早安问候、提醒、主动关心。
- 上线前先经营角色本身，提前积累受众。

### 11.4 BSide 的教训
- 只靠好看留不住人，套路化的回复很快让人腻。
- 全云端免费运营成本太高；小离本地运行，这正是优势。

## 12. 路线图
1. 定稿设计（本文档）。
2. 文字聊天 + 本地大脑的最小可用版。
3. 加上耳朵和嘴巴（语音对话）。
4. 加上形象和对话式配置。
5. 接入外部智能体、开放 DIY 和技能扩展。
