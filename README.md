# 小离 v0.6.1-dev（本地开发版，尚未发布）

一个住在你电脑里的 AI 小帮手。聊天和回复朗读完全离线，不用登录、不用联网、不用设置，只用 CPU。

## 下载和使用（Windows 10/11 64 位）

1. 到 [Releases](../../releases) 下载 `XiaoLi-v0.3-Windows-x64.zip`，右键选「全部解压缩」，不要在压缩包里直接双击。
2. 打开解压出来的「小离」文件夹，双击「小离.exe」。如果 Windows 提示有风险，点「更多信息」再点「仍要运行」。
3. 等几秒小离会先用文字打招呼，在左下角输入框打字、按回车就能聊。回复会逐句朗读，开始播放一句时显示这一句字幕；右上角可以开关声音。关闭窗口后小离会退出。

建议至少 4 GB 空闲内存、8 GB 或以上系统内存，另留出浏览器的内存余量。Linux 测试中启动器、大脑和语音进程合计峰值约 2.93 GiB；Windows 和长对话可能不同。

- 构建流程自动校验 TTS 下载 SHA256，随包保留模型许可证、README 和第三方组件说明。

## 目前的限制

- 句级合成，不是每个音频片段实时生成。按「。！？!?；;…、换行」断句；较长句在第 24–72 字之间优先按逗号分段，无逗号则 72 字截断。末尾不足一句也会朗读。
- 本机 Linux 实测短首句在句末后约 0.36–0.79 秒开始播放；长句、慢 CPU、首次加载和电脑负载会增加等待，不能保证每句都在 1 秒内播放。后续句要等前一句播完，字幕跟随播放。
- 浏览器首次有声播放需要点击或打字；欢迎语默认只显示文字。没有声音时可点击声音开关或输入一条消息。开启声音不会补播已跳过的内容。
- 静音设置依赖浏览器资料和本地 UI 端口；清除资料、删除 `ui-port.txt` 或原端口被占用而切换时可能恢复默认。
- 语音失败后本次会话静默降级，重启小离才会重新尝试加载；无语音识别、动画或长期记忆，关闭窗口不保存聊天记录。
- 1.7B 小模型可能答非所问，中文多音字、英文、数字的读音可能不准确。
- 左上角只显示日期和时间，没有接日历。程序没有数字签名，会有 SmartScreen 提示。

## 组成

- 启动器：Go（见 `launcher/`，构建说明见 `BUILD.md`）
- 推理：[llama.cpp b11799](https://github.com/ggml-org/llama.cpp/releases/tag/b11799) Windows CPU 版
- 模型：[Qwen3-1.7B Q4_K_M](https://huggingface.co/unsloth/Qwen3-1.7B-GGUF)（Apache-2.0）
- 语音：[sherpa-onnx 1.13.8](https://github.com/k2-fsa/sherpa-onnx/releases/tag/v1.13.8) CPU + [Melo 转换包](https://github.com/k2-fsa/sherpa-onnx/releases/tag/tts-models)；原始模型可见 [ModelScope](https://modelscope.cn/models/myshell-ai/MeloTTS-Chinese)。未核实到同格式的 ModelScope 转换包镜像，构建时使用 GitHub 官方包，运行时不下载。
- 第三方说明见 `THIRD_PARTY_NOTICES.txt`；完整包保留 `models/tts/LICENSE`、`models/tts/README.md` 和 `runtime/tts/licenses/`。


## v0.5-dev 第二阶段语音输入（本地开发，未发布）

点按麦克风开始，再点结束；按住至少 300ms 后松开结束。滑出按钮、Esc、失焦会取消并恢复原草稿。停止后仅在光标处填入文字，Enter/发送按钮才发送；整理期间按发送会等待 final 后发送一次。开麦会先停掉小离的朗读与旧回复。
录音和整理期间输入框暂时只读、浅灰显示，final 后恢复编辑；旧自动发送设置已移除。

麦克风权限、设备、模型或识别进程不可用时仍可打字聊天、听小离回复。
v0.5 仅本地分支，尚无下载包；上方下载链接为既有 v0.3。构建方式、许可说明见 BUILD.md 和 THIRD_PARTY_NOTICES.txt。

本地开发版已完成可读性、手动录音和中英双语流式预览；聊天模式留待第三阶段。

录音中使用本地中英双语流式 Zipformer 显示浅灰临时字，松开后 SenseVoice 整理为白字；确认后按 Enter 或发送。流式模型缺失时仍可在停止后整理文字。
